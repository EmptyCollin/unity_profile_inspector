# UPI 迭代计划（v2：两形态 + 探针优先 + UI 唯一通道）

> 状态：**执行中**。最后更新：2026-11-11（I0 完成、I1a 完成）。
> 本文是后续开发的单一路线图；与旧 DESIGN/AGENTS 冲突时，以本文 + 对应 ADR 为准。
> ADR：`docs/adr/0001`~`0005`。

## 0. 目标形态

一个本地常驻的 Unity 性能 Agent：

> **一个探针、两种形态（常驻 / 回归）、一套事件-聚类-指纹-修复核心；所有人类操作只通过本地 Web 控制台完成，CLI 只保留启动、诊断和应急。**

### 两种形态

| 维度 | 常驻形态（日常开发） | 回归形态（批量回归） |
|---|---|---|
| 数据源 | 常驻探针 + 1Hz 哨兵/抽检 | 确定性 replay + 测试目标 |
| 问题定义 | 预算线 / 相对基线 / 抽检异常 | replay 指令 + 测试目标 |
| 复现 | 不要求 3 次基线 | 3 次（或 N 次）基线 + 聚类 + 复现率 |
| 修复 | best-effort，编译/冒烟/可回滚 | 修 + 同 replay 重跑 + 重新聚类 |
| 结论 | `unverified`，不进成功率分母 | `verified`，进成功率 |
| 节奏 | 常驻 / 实时 | 批量 / 夜间 / CI / 里程碑 |

**硬规则**：常驻不得记 `resolved/verified`；回归的 `verified` 必须来自“同 replay、同 cluster 消失、无新 cluster、守护不劣化”。

## 1. 五条架构定调

1. **单探针**：合并两个注入件，一个回调、一个心跳、一条事件流；用户三态开关（关/稳态/全程）。1Hz 轮询只做哨兵。
2. **事件两类**：`breach`（确定越界，进修复循环）、`sample`（不确定抽检，只产候选）。
3. **cluster 是单位**：一个 replay/巡检里多个相同/不同问题先聚类再分类；修复和验证都以 cluster 为单位。
4. **批量工单、串行落地**：工单可列多个候选，按置信度排序；一次只落一个 patch，每步 snapshot → 编译/冒烟 → 观测 → keep/rollback → 下一个。
5. **UI 唯一通道**：本地 Web 控制台；文件只作审计载体；CLI 只启动/诊断/应急。

## 2. 数据与验证等级

```text
ProbeEvent(kind=breach|sample, frame, metric, value, series/ring, a4, protocol_fp)
IssueCluster(cluster_id, metrics, rel_range, shape, occurrences, reproduction_rate)
Fingerprint(features, pattern_id, root_cause, playbook_id, confidence, stats)
BatchTicket(id, mode, items[], status)
PatchAttempt(ticket_id, patch, snapshot, safety, observation, decision)
Verdict(mode, verification=unverified|observed|verified|failed, target, guards, new_clusters)
```

统计必须分账：`mode ∈ resident|regression`、`verification_status ∈ unverified|observed|verified`。

## 4. 验收

### 常驻形态
开探针 → 检出 breach/sample → 聚类 → 批量工单 → UI 批准 → 2+ patch 串行 → 一个失败回滚 → 全程 `unverified` 留痕。

### 回归形态
定义 replay + 测试目标 → 3 次基线 → cluster 矩阵 → 稳定 cluster → 修复 → 同 replay 验证 → `verified` 报告；失败可回滚。

### UI
所有人类操作在 UI 完成；不手工编辑 JSON/Markdown；CP936 正常；localhost 安全；关键流程有浏览器冒烟测试。

### 工程
旧测试保持绿；新增事件/聚类/指纹/执行器/UI API 测试；README/使用说明改为 UI 口径；旧 ANSI TUI 删除或标 deprecated。

## 6. 当前已知风险

- **I1b 是 C# 合并**：回调/心跳/句柄生命周期必须真机验证；在完成前，两个旧心跳仍存在。
- **聚类误合并/误拆分**：保守合并 + `ambiguous` 标记 + 人工可改。
- **3 次基线统计功效不足**：低复现率加跑/压力放大；不把 0/3 当强证据。
- **性能噪声**：同协议、3σ、必要时加跑；`unverified` 不冒充 `verified`。
- **UI 是唯一通道**：UI 挂了没人能操作；需要 break-glass 停止/回滚。
- **工作区脏**：`fixtures/upi-fixture` 的 Addressables 改动是既有未提交项，动夹具前先处理。
