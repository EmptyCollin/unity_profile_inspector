# I8 Lab 体验指南

## 启动

```bash
python scripts/i8_lab.py --port 8787
```

打开：

```text
http://127.0.0.1:8787
```

Unity 需要先可用：

```bash
python scripts/ensure_editor.py
```

- 有窗口但不可达：拒绝再开第二个；
- 没有窗口：只开一次。

## 建议体验顺序

### A. c01：BoardModel 分配

只勾选：

```text
c01
```

点：

```text
组合到临时工程
→ 应用到 base
→ 执行 replay
→ 采集候选
```

应该看到：

```text
BoardModel.FindMatches
BoardModel.FindMatchesBody
allocation_site:BoardModel.FindMatchesBody
```

### B. c02 + c03：HUD / item

只勾选：

```text
c02
c03
```

点：

```text
组合 → 应用 → replay → 采集
```

应该看到：

```text
UpdateHudBody
RefreshItemLabelsBody
```

### C. c04：资产

只勾选：

```text
c04
```

点：

```text
组合 → 应用 → replay（open_shop）
```

确认：

```text
phase=Shop
shopOpen=true
```

c04 目前只做资产检测，没有自动修复 recipe。

### D. 四个一起

勾选 c01-c04，体验组合工程与合并 replay。

注意：

```text
候选排序可能以 Board 为主；
HUD/item 可能不在 top8。
```

想看 HUD/item 时请单独选 c02/c03。

## Agent 诊断

点“Agent 诊断”会真实调用 DeepSeek：

```text
provider: deepseek-official
model: deepseek-flash
```

会产生 token 成本；诊断结果在：

```text
runs/i8_lab/diagnose.json
```

没有配置密钥时，会明确失败，不会静默降级。

## 修复

点“查看修复计划”先看：

```text
playbook
files
diffs
tier
```

点“执行修复”会：

```text
应用 recipe
→ 编译
→ 失败自动恢复 base
```

当前覆盖：

```text
PB-OP-BOARD-BUFFER-REUSE
PB-OP-HUD-TEXT-CACHE
PB-OP-ITEM-LABEL-CACHE
```

## 恢复

体验完必须点：

```text
恢复 base
```

它会：

```text
git checkout 被覆盖文件
停止 Play
检查工作区
```

## 当前可信边界

```text
组合/编译/replay          已验证
候选生成                  已验证
真实 Agent                已验证（有 token 记录）
代码 recipe 修复           已验证
性能 verified             未完成，只能 observed
c04 自动修复              未完成
Unity 后台/深度采集        仍有环境敏感性
```

## 安全约定

- 不自动开第二个 Unity；
- 不删除 Scene Backup；
- `Assets/_Recovery` 保留并忽略；
- apply 前要求 `sim/project` 干净；
- 编译失败自动恢复。
