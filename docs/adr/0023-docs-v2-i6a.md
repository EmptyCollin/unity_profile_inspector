# ADR-0023：README/使用说明 v2 重写（I6a）

- 状态：已完成（2026-11-11）
- 关联：ADR-0022、`README.md`、`docs/使用说明.md`

## 背景

README 仍写“I0/I1a 骨架、24 套测试、dev tui”，使用说明仍是旧 TUI 按键手册；
用户按文档操作会找不到入口，违反“UI 是唯一通道”。

## 决策

- README 重写为当前 v2 概览：两形态、快速开始、当前 I5b2、能力边界、
  目录/测试/文档索引；
- 使用说明重写为 Web 单通道手册：
  1. 两形态；2. 启动；3. 装探针/采样；4. 页面；5. 常驻；6. 回归；
  7. 证据/审批；8. 故障；9. 命令表；10. 盲区；
- 删除所有“`dev tui` 按键”用法；只保留“入口已移除”说明；
- 明确当前边界：夹具 blocked/脏区、真实 replay 命令由用户提供、没有
  自动修夹具的虚假承诺。

## 验证

- 文档内命令与 `python -m upi dev` 实际列表一致（无 tui）；
- 测试口径更新为 31 套；
- 代码未改，离线套件仍 31/31 通过（上一轮已跑）。

## 边界

- 文档仍不是完整“接入向导”；Web 向导在 I5b 之后；
- 没有截图/交互式教程；
- 真实工程 E2E 仍未做；文档明确标注。
